
# Dataset

This project uses six source datasets for vendor performance, profitability, inventory, and purchasing analysis.

| Dataset           |    Records |
| ----------------- | ---------: |
| `begin_inventory` |    206,529 |
| `end_inventory`   |    224,489 |
| `purchases`       |  2,372,474 |
| `purchase_prices` |     12,261 |
| `sales`           | 12,825,363 |
| `vendor_invoice`  |      5,543 |

The complete raw datasets are provided as a compressed archive because of their large combined file size.

### Download Full Dataset
